# engine-node example

Этот пример запускает воспроизводимый бэктест RSI(14) на синтетических OHLC-данных.
Сетевой доступ и API-токен не требуются.

## Запуск

Требуется Node.js 22 или новее. Установите зависимости из корня репозитория:

```bash
npm install
npx tsx examples/engine-node/rsi-bot-backtest.ts
```

В выводе появятся количество баров, число закрытых позиций и значения критериев
доходности, просадки и Sharpe ratio.

## Что показывает пример

- создание `BarSeries` из OHLC-данных;
- RSI(14) и правила входа/выхода;
- `BarSeriesManager` с сайзером, проскальзыванием и комиссией;
- расчёт критериев бэктеста.
