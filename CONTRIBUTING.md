## Как опубликовать в Open Source?

Для версионирования и публикации используется [Nx release](https://20.nx.dev/recipes/nx-release/get-started-with-nx-release).

Все библиотеки в репозитории разделены на группы, каждая из которых имеет свои правила версионирования.

### contract
В эту группу входят следующие библиотеки:

* `grpc`;
* `grpc-node-client`;
* `grpc-web-client`.

Версия этих библиотек привязана к версии контракта и является общей для всей группы.
Это сделано потому, что при обновлении контракта нужно обязательно обновить генерируемые клиенты.

Для обновления версии конрактов нужно сделать следующее:

1. Скачать из [репозитория](https://opensource.tbank.ru/invest/invest-contracts) файлы контрактов, положить их в `libs/grpc/proto` и закомитить результат;
2. Выполнить команду `nx release --skip-publish --group contract`, которая предложит выбрать версию. Версию нужно выбрать ту же, что и у контрактов;
3. В результате выполнения команды будут обновлены версии в соответвующих `package.json`, создан тэг и коммит. Эти изменения нужно доставить в `main` внутреннего репозитория;
4. После этого нужно доставить изменения в OSS репозиторий. На момент написания это [ttech-pub/invest-js](https://github.com/ttech-pub/invest-js). Для этого: переключиться на мастер, обновить его и выполнить команду `git remote add oss git@github.com:ttech-pub/invest-js.git`;
5. Запушить все изменения и тэг в OSS репозиторий – `git push oss main --follow-tags`. После этого Github Action сделает все остальное.
